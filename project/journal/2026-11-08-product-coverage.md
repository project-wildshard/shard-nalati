The lift is out, so this checkout now owns an explicit outer-edge proof of
its built products against the installed, pinned engine and sharddev. Real
player commands walk for 240 ticks; a checkpoint resumes with an identical
five-tick continuation. No host, save field, generated row or private method
is pinned. Each case has a 9.5 second cap and disposes its world in finally.
It runs only in CI or explicitly, never in either git hook.

Ring 3 accepts full engine and sharddev commit hashes through dispatch.
Overrides cover transitive engine edges too. Normal pushes retain frozen
tag dependencies. The candidate lane builds and runs this shard's own
tests; it neither uploads nor deploys anything. A missing candidate export
or a failed play path fails the workflow normally.

than reaching into the installed package's private tree. This proof shows
