# sdk 0.6.1: format 0.79.2, and main's check green again

> Written by: Claude (lane opus-nalati), 2026-11-25, meta QA 11-24 row 70 and FORMAT-PRUNE FP61

`wildshard update --pins=0.6.1` moved the SDK pins to 0.6.1 and the format to 0.79.2. Its 0.5.0 step found one file
still under `public/` (the map's `top.webp`); the lean-layout repair (`adef986`) deleted that copy first, so this move
keeps that. The docs that named `public/assets/` now name `src/static/`.

The author lint switches off `import/namespace`: three 0.186's module re-exports its classes with `export *` from
`three.core.js`, which oxlint 1.89's rule does not follow, so it reported 866 false "not found in imported namespace"
errors on `THREE.Color` and the like. TypeScript checks those names.

The grass keeps its card clumps for now: engine's pinned format (0.78.0) still requires them, and a shard without them
stops at `level.world` ("Expected cards"). Dropping them is the rest of row 70, after engine reads format 0.79.
