# Keep one Nalati boot roster

The physics bake owns the 35 ordered bodies and four herd memberships.
The boot document keeps their adoption streams and the herd centres.
This drops the boot document from 109,419 to 79,431 bytes.

The packed server boots both layouts with the same snapshot and effects
for 120 movement ticks. Restoring the older save into the new layout
also gives the same five-tick continuation.
