# Run the three relocated Nalati author tools

CI21 NAL-TOOL brings the three author command checks to their source
repo. The first real invocation failed to find the old local byte
writer. The local author-tool adapter uses the public engine export.
The commands retain their original imports and the author Node loader.

Crag and contact checks compare the complete committed bytes. The
sign command can write to an owned output directory for the proof.
It checks every atlas and lettered board through headless Chromium.
The original sign check still compares exact bytes on the author
host. Ring 2 installs Chromium for this native authoring proof.
