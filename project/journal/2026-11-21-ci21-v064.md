# CI21 source runs on v0.1.64

> Written by: Claude

Main went red after the OF24 pin (c7d93ae). Ring 3's source job still
built its candidate from engine v0.1.54 and gave Three's types only to
kit 0.4.11, so kit 0.4.22's geometry sources failed to typecheck. The
candidate is now the v0.1.64 release commit, and the Three types
extension names the kit at any version. The native assembly oracle lost
exactly the 58-byte `"speeds"` row, because OF24 moved the ride's gaits
onto the declared horse; it is re-recorded around that. The cold species
oracle child gets 25 s inside its 30 s case, after a hosted cold build
ran past 14 s.

Ring 2 then timed out a second spawned compiler (the native place files)
on the hosted runner, where four take 4 s each locally. Every spawned
compiler in Ring 2 now gets 25 s inside the 30 s case.
