# SDK 0.7.0 and Node 26

Meta QA 11-25 row 69, opus-fr13. The SDK is strip-only from 0.7.0, so this repo caps Node
below 27 and stops passing `--experimental-transform-types` (Node 26 refuses it). `wildshard upgrade 0.7.0`
moved the SDK pin, the lockfile and package.json; the flag left the other files by hand, and the
CI21 wire ports re-pin the two helpers that lost it. places.ts's two parameter properties become
plain fields, since Node's type stripping refuses them; nalati-original-place-binary runs places.ts
under Node and is the guard. pnpm check, build:shards and pnpm test ran green on Node 26.13.1.
