# Format pin to v0.4.4

> Written by: Claude (opus-nalati-build), 2026-11-13

`pnpm build:shards` broke on main after `8f92bfe` moved sharddev to
`efbdc25`: that sharddev's `cookInput.ts` imports
`@wildshard/format/audioWaiver` (the AU5 audio waiver), which shard-format
first exported in v0.4.3. The format pin and its `pnpm.overrides` entry
stayed at `0786a04` (v0.4.2), so the bundler could not resolve it.

Both now name `17539ea`, the v0.4.4 tag commit: sharddev `efbdc25`'s own
format pin, so the pair moves together as the hero-stamp journal says.
v0.4.5 was the other choice; it is not what sharddev or engine `867f3b9`
were tested on. The package is named `@wildshard/shard-format` since
v0.4.4 and installs under the `@wildshard/format` alias, as in sharddev.
Engine stays at `867f3b9`; the override hands it v0.4.4 too.

Built in a clean clone: the product's 331 files match uploaded rev 2
(`77b77fcc`) except kokpar's wasm, `quests/content.json`,
`quests/carried.json` and `held/slots.json`, all from the tai-qazan fix
`48d2b30` (new wasm hash, `goalReach`). `build.validator` changes with the
format, so a new upload would get a new hash. Nothing was uploaded.
