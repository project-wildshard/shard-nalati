> Written by: Codex

> **State:** in progress, 2026-11-16.

These complete original files need engine source that is not published.
They remain on engine's pending inventory. This separate strict compiler,
typed lint, retention and Vitest gate runs in Ring3 when an exact candidate
engine is installed. Default owner discovery is admitted only after C11
publishes the source and promotes these files; no current source removal
or default-suite equivalence is claimed.

`pnpm check:ci21-candidate` checks every original case and frozen input.
The current local proof used a packed engine with the uncommitted source
patch at `tmp/codex-tc48/engine-c3-source.patch`; hosted proof remains owed.
No shim, invented engine type, ignored compiler error or changed oracle.

The candidate graph deliberately keeps two format generations: the author's
existing pin and the candidate engine's exact declared minimum. The installed
engine source and that resolved dependency are the qualification target; C11
must qualify the final published dependency graph again. Every extraction
helper and provenance transform is hash-pinned and explicitly type-linted.

The final C3 group contains sixteen whole originals and forty cases.
Its strict compiler admits the actual engine declaration merges through
the prepared public game/types entry; exactOptionalPropertyTypes matches
the engine compiler. postprocessing and navcat resolve real @types/three
through packageExtensions, needed by pnpm's isolated dependency graph.
All fixture/fake input bytes are retained in supportFixtures, and the
full compiler-discovered test/helper closure is explicitly typed-linted.
Native compilation uses real public SDK entries and the existing fenced
engine recorder cache. No test verdict is cached.

The 179-file support inventory deliberately also binds archived fixture
helpers; it is not a claim that every file executes in these sixteen
tests. The retention gate computes the actual compiler closure and
requires both typedLintFiles and the lint command to cover it exactly.
